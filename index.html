What’s new

AI quality

  • Per-chat model locks, chat-specific instructions, reasoning and temperature overrides now work alongside project and global defaults.
  • Strict JSON Schema output, second-pass AI review, review-driven revision, comparison synthesis, and automatic long-chat summarization remain available.
  • Model selection can now learn from your own local 👍/👎 ratings and pick the best-rated compatible model.

Reliability

  • Oversized requests are stopped before they hit a model context limit, with the draft and attachments restored automatically.
  • Transient 429/502/503/504 API failures now get a bounded retry sequence with Retry-After support before falling back to a visible error.
  • A configurable network-stall watchdog can abort requests that stop returning data instead of hanging forever.
  • Per-request and daily tracked-spend warnings help catch unexpectedly expensive calls before sending.

Workspace

  • Conversation branch lineage shows parent/child forks and lets you jump across alternate paths.
  • Conversation Tasks adds a persistent per-chat to-do board with optional AI task extraction.
  • Tasks survive snapshots, branches, chat backups, and imports; media persistence, archives, trash, global search, and encrypted backups remain intact.

Interface

  • You can now type the next prompt while a reply is streaming, queue it with the new Queue button or Alt+Enter, and let Quantum Breaks AI continue into the next turn automatically.
  • Queued prompts stay attached to the conversation if a request is stopped or fails, and can be moved back into the composer or removed before they run.
  • Keyboard-shortcut help, clickable conversation titles, live tab titles, optional background completion notifications, and expanded model sorting improve daily use.
